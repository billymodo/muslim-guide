# Licensing Policy

## Golden Rule
**UNKNOWN = BLOCKED**

المورد يُعتمد فقط عندما:
1. الحقوق محددة.
2. حقوق إعادة التوزيع مثبتة.
3. التضمين في التطبيق متوافق.
4. الشروط معروفة.
5. الشروط مُحقَّقة.
6. الدليل محفوظ.
7. الإصدار المُراقَع = الإصدار المُشحون.

## Important Distinctions
- Website access ≠ redistribution permission
- API access ≠ content license
- GitHub repository license ≠ data license
- Open source code ≠ open religious text
- Free access ≠ free redistribution

## Development Mode
يُسمح بـ placeholders في التطوير مع علامة صريحة:
- `[PLACEHOLDER-XXX]`
- لا تُشحن في الإنتاج.
- CI يفشل إذا وُجد placeholder في `main`.

## Expired Review
مراجعة منتهية = **BLOCK**.
