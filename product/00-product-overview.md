# Product Overview

## Product
دليل المسلم

## Primary Goal
تطبيق إسلامي شامل، Offline بالكامل، بلا حسابات، بمحتوى معتمد، باللغتين AR/EN.

## Target Platforms
- Android (min SDK في OD-0006)
- iOS (قرار OD-0006)

## Core Features (v1.0)
- مواقيت الصلاة
- القبلة
- الأذان والإشعارات
- الأذكار
- القرآن
- التلاوة
- التقويم الهجري

## Non-Goals
- Social، حسابات، telemetry، إعلانات.

## UX Principles
- بسيط، واضح، بلا تعقيد.
- RTL-first.
- Offline-first.
- وصولية كاملة.
