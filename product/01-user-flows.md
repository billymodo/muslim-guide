# User Flows

## FLOW-001 — أول تشغيل
- **Entry**: فتح التطبيق أول مرة.
- **Steps**: Splash → اختيار اللغة → Onboarding → الإعدادات الأساسية → الرئيسية.
- **Failure States**: فشل Hive → رسالة + وضع آمن.
- **Related Requirements**: REQ-FOUND-001
- **Related Screens**: SCREEN-001, SCREEN-002

## FLOW-002 — إعداد الصلاة
- **Entry**: من الإعدادات.
- **Steps**: تحديد الموقع (GPS أو يدوي) → اختيار طريقة الحساب → حفظ.
- **Related Requirements**: REQ-PRAYER-001
