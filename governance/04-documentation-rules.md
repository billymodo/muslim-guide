# Documentation Rules

## Single Source of Truth
لكل حقيقة مكان واحد. البقية تشير ولا تكرر.

## No Contradictory Copies
ممنوع نسخ قيم سياسة متغيرة في ملفات متعددة.
مثال خطأ:
- `policy.yaml` يقول X
- `requirements.md` يقول Y

الصحيح: `policy.yaml` هو المصدر.

## Versioning
كل وثيقة جوهربة تُظهر:
- status
- owner
- last updated
- related decision
