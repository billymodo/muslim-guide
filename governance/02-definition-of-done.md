# Definition of Done

المهمة "منتهية" فقط عندما:
- [ ] Requirement محدّد
- [ ] Scope محدّد
- [ ] Implementation مكتمل
- [ ] Tests مضافة/محدّثة
- [ ] Documentation محدّث
- [ ] Dependencies مُراجعة
- [ ] Legal review مُكتمل (حيث ينطبق)
- [ ] CI ينجح
- [ ] لا فجوة مانعة
- [ ] Evidence مُسجَّلة
- [ ] PR مُراجَع
- [ ] Deviations مملوءة (حتى لو "لا يوجد")
